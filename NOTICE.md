## Changes made (Apache-2.0 §4b)

Generated by `scripts/build_from_upstream.py`, by text rules only:

- integration domain `spotifyplus` / `spotcast` → `aureon_music`; imports point to the sub-packages above;
- each part keeps its own `hass.data` key (`aureon_music_spotifyplus`, `aureon_music_spotcast`);
- SpotifyPlus names (`SpotifyPlus…` intents, services, token file `aureon_music_tokens.json`) renamed `AureonMusic…`
  so an installed original never collides;
- the config flows are not registered on their own; `config_flow.py` shows a menu and then runs the original flow;
- service descriptions, texts and translations of both are merged; brand images are not included.

Behaviour, API calls and authentication are those of the original projects.
